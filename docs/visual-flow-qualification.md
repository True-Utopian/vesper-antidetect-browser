## What the editor supports

**Branch by page** routes freshly recognized pages to compatible steps. **Repeat steps** repeats an explicit body between 1 and 99 times, then follows its exit route. Body selection, count, page routes and exits have forms. **Flow settings** exposes recognized pages and shared execution limits. **Arrange flow**, saved positions, recovery edges and Undo/Redo make the graph editable without making layout determine execution order.

Saving changed execution content advances its patch version. Unchanged or layout-only edits preserve execution identity. Publication reserves an immutable deployment version; an admitted run keeps its original definition. A normal restart can bind the owned demo's new local origin to a higher version without overwriting a previous deployment or saved archive. External deployments retain their explicit origin and immutable-version checks.

The compiler rejects incompatible page routes, malformed bodies, missing return paths and exits that re-enter their own controller/body. Repeat counters are durable before body dispatch and consume the existing visit, step and time limits. Pending mutations keep their uncertainty fence. A loop count never grants permission to repeat an uncertain website action or promises exactly-once effects on an external service.

## Reproduce and assess the scope

The public source regression suite exercises branch routing, repeat limits and nesting, durable counters, uncertainty handling, version floors, immutable publication and restart rebinding. The complete local source suites passed **296 tests with two skips on Windows** and **291 with seven skips on Linux**, with no failures. The independent Browser checkout passed **102 tests**. Use the repository's documented source checks and [flow authoring guide](flows.md) for the source contract and editor instructions.

For a desktop walkthrough, use a fresh developer-owned store and an owned website. Create a flow, add a recognized alternate page and compatible branch destinations, add a repeat with a count of three, and give its body a return route. Save and publish. Run the matching page and alternate path separately, finish and save each run, verify its archive, then quit normally and repeat after restart. Inspect only a stopped copy of an owned database; do not open the operator's live database or reuse private qualification outputs.

The native kernel bytes did not change. The kernels retain their 26 recorded unit executions per platform; fresh copied-runtime checks passed nine cases, and Linux's new selected installed path passed nine cases before guarded activation and a fresh profile backup. This provides no additional WebGL/WebGPU/audio/font/media/screen masking coverage.

Linux acceptance used the existing isolated per-user workspace, Xvfb and explicit software graphics. Windows standalone NSIS installation and Authenticode publisher signing remain unqualified.
