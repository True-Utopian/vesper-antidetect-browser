# Vesper desktop identity

Vesper Browser and Vesper Workbench are by true-utopian. The original moth emblem uses the evening meaning of Vesper and has no connection to vendor artwork. The desktop uses charcoal surfaces (`#181a20`, `#22252d`), soft blue (`#b4c8ff`), neutral text (`#e8ebf2`, `#a5aebe`) and a quiet green state indicator (`#a9d1b7`). Segoe UI Variable/Segoe UI and system fallbacks keep the interface readable on Windows and Linux.

Profiles are the primary collection: folders and running/favorite views on the left, search and filters above a compact table, contextual actions at each row, and pagination below. Workbench remains an optional add-on rather than a second profile store. Its flows and schedules share the desktop surfaces.

Browser 0.4.4 reduces the table's minimum width to 960 pixels while keeping every column and row action. The owned desktop fixture fits at 1280 and 1366 pixels without horizontal scrolling. Below that width, the profile table can scroll without narrowing the sidebar or hiding profile actions. Workbench 0.5.6 scopes its host-mode palette consistently on the body, so embedded and standalone controls resolve the same blue primary (`#b4c8ff`) and dark label (`#151d32`). Calendar editing keeps a fixed save footer while its form scrolls within the available native view.

The raster emblem was generated with the built-in image generation tool. Final prompt: “Production desktop app icon for Vesper Browser by true-utopian: one original elegant geometric moth with broad swept wings, a small slender central body, and simple ivory crescent cutout details. Flat solid periwinkle-blue shapes on a uniform charcoal square background. Strong balanced silhouette, clean edges, no words, letters, shields or AI sparkles.” The original output is retained locally; `public/vesper-icon.png` is the production asset. The SVG mark remains as a compatibility asset for external clients.
