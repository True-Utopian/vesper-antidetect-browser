Release availability

Source is public. Tested installers remain local.

Browser 0.4.12 / Workbench 0.5.17 is the accepted local pair. Windows installed integration and both Linux portable products passed their scoped checks. Public runtime downloads and a hosted update feed are not available yet.

Build from source

Choose the original repository and follow its desktop build documentation. Workbench requires Node.js 26 or newer; independent Browser supports Node.js 24 or newer. Desktop apps include their runtime. Kernel developers need a separate Chromium toolchain; end users need only compiled packages.

Browser sourceWorkbench source

Already have local packages?

Follow the Windows or Linux installation guide. Check the matching manifest and checksum, finish active work and retain a verified backup before replacing an installed app.

What is still pending?

Public binary distribution, Windows Authenticode publisher signing, broader Linux targets and the full recovery matrix remain unfinished. See every named check rather than assuming source availability means a complete public release.
